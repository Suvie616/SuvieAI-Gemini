========================================
  SUUWETHAAN AI — RUN INSIDE VS CODE
========================================

1. Open VS Code
2. File → Open Folder → select your project folder
3. Install Python extension if asked
4. Terminal → Run Task → "SUUWETHAAN AI: Setup (venv + install)"
5. Ctrl+Shift+P → "Python: Select Interpreter" → pick .venv
6. Open js/firebase-config.js and PASTE your Firebase web config
7. In Firebase Console:
     - Authentication → Google → Enable
     - Firestore → Create database
     - Firestore → Rules → paste firestore.rules → Publish
8. Press F5  (Run and Debug → SUUWETHAAN AI: Run Server)
9. Open http://localhost:5000
   IMPORTANT: use localhost — NOT 127.0.0.1
   (Firebase blocks 127.0.0.1 by default)
10. Click "Sign in with Google" → chat → history saves to Firebase
    If popup is blocked, click "Sign in (redirect)"

If sign-in still fails, open the browser console (F12) and read the red error.
Common fixes:
  - Authentication → Sign-in method → Google → Enable
  - Authorized domains must include: localhost
  - Allow popups for localhost

Gemini API key is already in the .env file.
